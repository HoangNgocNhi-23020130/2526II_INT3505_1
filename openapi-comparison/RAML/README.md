# RAML Demo

1. Copy nội dung file `api.raml`.
2. Truy cập công cụ thiết kế trực tuyến [Anypoint Design Center](https://anypoint.mulesoft.com/login/).
3. Tạo một "API Specification" mới và chọn chuẩn RAML 1.0.
4. Dán code vào, hệ thống sẽ dựng giao diện API Console ở bên phải cho phép đọc tài liệu và gửi thử Request.
