# TypeSpec Demo

1. Copy toàn bộ nội dung file `typespec.tsp` trong thư mục này.
2. Truy cập trang Playground chính thức của Microsoft: [TypeSpec Playground](https://typespec.io/playground)
3. Dán code vào khung bên trái.
4. Ở khung bên phải, TypeSpec sẽ tự động biên dịch code thành chuẩn `OpenAPI 3.0`.
5. Dùng code openapi đó để demo giao diện (tham khảo readme openapi).
