# OpenAPI Demo

## Cách 1
1. Copy toàn bộ nội dung file `openapi.yaml` trong thư mục này.
2. Truy cập trình duyệt vào trang: [Swagger Editor](https://editor.swagger.io/)
3. Dán code `openapi.yaml` vào khung bên trái.
4. Giao diện tài liệu UI sẽ ngay lập tức được dựng lên ở khung bên phải.
